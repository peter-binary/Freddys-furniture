# Freddy's Furniture
Freddy's custom furniture website — built by Freddy, for Freddy.

## Deploy to GitHub Pages
1. Create a new repo on GitHub
2. Push this code: `git push origin main`
3. Enable GitHub Pages in repo Settings → Pages → Source: Deploy from branch (main)
4. Site will be live at `https://<username>.github.io/<repo-name>/`

## Security Features
- Content Security Policy (CSP) via meta tag
- X-Content-Type-Options: nosniff
- Referrer-Policy: strict-origin-when-cross-origin
- No external dependencies beyond Google Fonts & Unsplash images
